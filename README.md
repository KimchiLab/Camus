# Camus
Camera for homecage recordings of Mus musculus mice  
**"the whole of life can be summed up in an image"** - Albert Camus, *Between Yes and No*

The following is a representative image of Camus recordings, from a camera placed on the ceiling within a standard lab mouse homecage. The homecage is housed on a standard individually ventilated cage (IVC) rack.

### Repository Organization
The repository is split into Hardware and Code folders.
1. [Hardware](Hardware): Contains instructions and designs for building and setting up cameras
2. [Code](Code): Contains instructions and code for installing the software to collect and analyze data.
